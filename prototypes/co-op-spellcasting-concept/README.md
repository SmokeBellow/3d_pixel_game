# Prototype: Co-op Spellcasting

**Hypothesis**: If two players independently cast elemental spells (Fire/Water/Lightning)
on the same enemies in real time, cross-player synergy (Water soaks a target, then
Lightning triggers a 3x-damage Chain Shock that jumps to nearby enemies) will feel
spontaneous and fun to discover — measurable by players triggering Chain Shock without
being told the combo exists, and describing the moment as satisfying/exciting in debrief.

**Riskiest assumption tested first**: That the *emergent discovery* of the combo (not the
mechanic in isolation) is what creates the fun — this is why two independent local players
control separate characters rather than one player controlling both.

**Scope**: Local two-player split-screen only (no networking). Auto-targeting instead of
FPS aiming (aim precision is explicitly out of scope for this test). One synergy pair only
(Water + Lightning = Chain Shock).

**How to run**: See chat — run instructions were provided directly by the assistant per
project convention (no separate setup doc). Summary: open the prototype project in Unity,
use `Tools > Co-op Spellcasting Prototype > Build Scene`, then Play.
